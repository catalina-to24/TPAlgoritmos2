🌳 BST invariante

En un Árbol Binario de Búsqueda, para cada nodo se cumple izquierda < nodo < derecha. Por eso el recorrido in-orden siempre devuelve los valores ordenados de menor a mayor.

↪ In-orden izq · nodo · der

Recorre el subárbol izquierdo, visita el nodo, y luego el derecho. Resultado: secuencia ordenada ascendente. O(n) tiempo.

↩ Pre-orden nodo · izq · der

Visita el nodo primero, después izquierda y derecha. Útil para copiar/serializar el árbol (la raíz sale primero). O(n) tiempo.

↯ Post-orden izq · der · nodo

Recorre ambos hijos y visita el nodo al final. Útil para liberar/borrar o evaluar de abajo hacia arriba. En el TPO se usa para la auditoría. O(n).

↡ Por niveles (BFS) cola

Recorre nivel por nivel de izquierda a derecha, usando una cola. Es el reporte por nivel N del TPO. O(n) tiempo.

🔍 Búsqueda O(log n)

Desde la raíz, se compara con cada nodo y se baja a izquierda o derecha. Promedio O(log n), peor caso O(n) si el árbol está degenerado.
